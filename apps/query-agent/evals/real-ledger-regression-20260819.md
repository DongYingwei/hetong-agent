## 执行与准确率记录

1. 每次在某环境验收前，先记录合同/订单总数和 AI 数：

```sql
-- contracts
SELECT count(*) AS contracts, count(*) FILTER (WHERE tag_ai=1) AS ai_contracts
FROM contracts WHERE confirmed=1;

-- contract_assistant
SELECT count(*) AS orders, count(*) FILTER (WHERE tag_ai=1) AS ai_orders
FROM sys_order WHERE delete_status=0;
```

2. 合同数据与本文件相同的环境可直接执行 C01–C10。订单数据若已重新导入，先用实际数据库结果更新 O01–O10，再执行验收。
3. 准确率按“关键事实全部正确”的用例数计算：`通过用例数 / 20`。不要仅用模型是否调用成功作为准确率。
4. 当前完成的是 **20 条标准答案的数据库核验（20/20）**；尚未逐条跑完在线大模型回答，因此不能把“标准答案核验”表述成“智能体端到端回答准确率”。端到端执行后，把每条实际回答、通过/失败和失败原因补在本文件末尾。
