# 金额口径与语义时间的查询纪律

查询侧信任正式库内的金额值（数值与口径均已人工核对入库），但仍须遵守两条不可隐式违反的口径纪律，否则会在 SQL 层制造失真、伤害 >90% 一致性。

## 决策

- **金额**：`SUM(amount)` 一律带 `WHERE amount IS NOT NULL`（"无金额合同"是合法类别）；结果集混含多种 `amount_type`（上限/固定/预估）时**分口径分组求和并分行标注**，不隐式合一；税率是 TEXT，不做数值运算。
- **语义时间**：不在 schema skill 里维护"用户说法→过滤条件"的固定映射表；schema 只声明物化列语义（`sign_half=1` 即上半年含 Q1Q2 等），由智能体在检索时自行推理该用哪列（Q4 选项 B）。

## Consequences

- schema skill 删除旧的硬映射表与"严禁模型自行推理"表述，改为声明列语义 + 由 Agent 推理——两处原本互相矛盾，此 ADR 消除该矛盾。
- 一致性风险（同一时间短语推理漂移）由 evals 首版 gate 的 trajectory/语法/口径断言守住；数值真值比对随测试库后续建立（见排期）。
