# 前端维护与验收说明

最后更新：2026-08-19。前端代码位于 `apps/web/`；视觉基准为
`demo/经小管-合同管理智能体原型v1.3.html`，接口和数据口径以本仓库后端为准。

## 本地运行与构建

```bash
cd apps/web
npm install
npm run dev -- --host 0.0.0.0 --port 5174
npm run build
```

前端统一请求同源 `/api`：开发环境由 Vite 代理，生产环境由 `jingxiaoguan-web` Nginx 转发。不要在浏览器中拼接 `:3002`，否则登录刷新、跨域和反向代理路径都会不稳定。

登录令牌保存于 `localStorage.contract_token`。普通 JSON 请求与 PDF Blob 预览请求都必须携带 `Authorization: Bearer <contract_token>`。

`npm run build` 同时执行 Vue 类型检查；必须通过才允许发布。Vite 对大 chunk 的提示是性能优化建议，不是构建失败。

## 当前页面行为

### 合同台账与详情

- 列表的四个模块只显示 `AI` 或 `—`，筛选项来自模块配置，不固定写死列。
- 已核对合同主操作为“查看”，未核对合同主操作为“核对”。查看弹窗只读；更多菜单提供编辑、查看原文件和删除。
- 点击合同号打开详情页，必须保留六个页签：基本信息、合同-金额及结算、合同-商务条款、风控管理、关键词解析、原文件预览。
- 基本信息展示“合同检索信息”“合同-概要信息”；金额及结算的结算条款可占整行；商务条款必须展示是否涉及后评估、履约保证金金额、履约保证金退还条件、仲裁方式、授权人。
- 关键词解析展示四模块识别结果及命中明细。明细中的“关键词”是命中的子词，“所属大类”是关键词管理的父词；无识别置信度列。
- 原文件预览应列出同一合同关联的全部 PDF，并可逐份切换预览/下载；不可只取第一份。
- 人工核对页只保留底部一个“保存已核对数据”按钮，使用系统主题色；不要再添加右上角重复保存按钮。

### 订单台账

- 列表字段和综合检索订单结果保持订单台账的 17 列口径。
- 列表可打开详情并编辑；详情页没有编辑入口。编辑使用普通文本输入，不用数值加减控件；保存后关闭弹窗。
- 明细税率按原精度显示，缺失值只显示 `—`，不能显示 `—%`。
- 订单人工编辑是覆盖层，不能伪装为 EPMS 原始数据，也不能被页面静态数据替代。

### 关键词与模块配置

- 关键词管理主表不展示“包含子词”列；展开行展示子词及子词数量。
- 模块配置的适配范围为“仅合同”“仅订单”“合同+订单”；合同和订单的模块列、筛选项均按此配置生成。
- 关键词重扫任务使用真实后端接口，只更新 AI 标签/命中，不重解析附件或向量。

### 综合检索与系统页面

- 结构化查询返回合同或订单台账表格，默认显示前 5 条并提供“查看全部明细”原地展开；不向客户展示 SQL、提示词或模型内部过程。
- 合同结果显示合同台账的 15 列，订单结果显示订单台账的 17 列；导出保留完整 Excel 表头和数据。
- 登录页背景与登录后主界面一致；组件主色应遵循当前主题，不能恢复为旧绿色。
- 首页用户名、姓名等必须来自当前登录用户/接口，不可写死 `admin` 或演示名称。

## 必须保留的接口

| 场景 | 关键接口 |
|---|---|
| 合同列表/详情 | `GET /api/contract/list`、`GET /api/contract/detail/:id` |
| 合同核对/编辑 | `POST /api/contract/verify/:id`、相关编辑接口 |
| 合同多 PDF | `GET /api/contract/:id/source-files`、`GET /api/contract/:id/original-pdf?sourceId=<id>` |
| 订单列表/详情/覆盖编辑 | `GET /api/order/list`、`GET /api/order/detail/:id`、`PUT /api/order/detail/:id` |
| 模块/关键词/重扫 | `/api/section/*`、关键词管理和任务接口 |
| 综合检索 | Gateway `/api/agent/*` 相关接口 |

接口缺字段时，应补后端契约或明确显示“暂无数据”，不得用 mock 数据代替真实台账。

## 发布前快速验收

1. `npm run build` 通过。
2. 登录后刷新、合同台账、订单台账、综合检索不出现 404 或 `Invalid URL`。
3. 随机打开一个多 PDF 合同，验证 PDF 切换、查看只读和编辑可保存。
4. 核对合同详情的金额及结算、商务条款与台账非空字段一致。
5. 在关键词管理展开一个父词，验证主表无“包含子词”列且展开内容正确。
