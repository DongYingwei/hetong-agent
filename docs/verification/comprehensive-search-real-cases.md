## 使用规则

- 在页面“综合检索”中逐条输入“输入问题”。
- 结构化用例应返回稳定的表格、金额或数量；结果可直接与“预期事实”核对。
- RAG 用例要求返回相关合同及正文出处。向量召回和精排的顺序可能变化，**不把第一名写成验收条件**。
- 当前 60 个词只用于关键词扫描和台账模块标识；综合检索遇到具体技术词时通常走向量检索，而不是精确关键词过滤。
